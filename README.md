# Record Manager

This repository only holds the releases. To install, download
`RecordManagerSetup.exe` from the latest release on the
[Releases](https://github.com/cduke0/record-manager-releases/releases/latest)
page and run it. It installs for your Windows account (no administrator
rights) and keeps itself up to date from here.

Windows may warn that the file is from an unknown publisher, because it is not
code-signed: choose "More info", then "Run anyway".
